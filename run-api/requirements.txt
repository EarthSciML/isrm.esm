# so `--quote-only` and a sign-in work from a bare interpreter.
#
#   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
#   .venv/bin/python run_isrm_demo.py
#
# NOTE this is not run-py/requirements.txt. That one builds the engine locally
# (EarthSciAST + EarthSciIO, editable, plus a multi-GB chunk cache); this one
# talks to a server that already has it.
matplotlib

# --- the notebook -----------------------------------------------------------
# `ipykernel` is what makes this venv runnable as a notebook kernel, in VS Code
# and in anything else that speaks the Jupyter protocol. VS Code needs no more
# than this — it brings its own front end.
ipykernel

# The .esm documents are built, analysed and validated with the format library
# itself rather than by hand. Base install is jsonschema + sympy + pint + numpy;
# nothing here pulls the netCDF/zarr/solver stack, which is the point -- this
# talks to a server that already has the engine.
earthsci-ast

# `run_isrm` takes a GeoDataFrame, so geopandas is what the notebook is about --
# it also brings numpy, pandas, shapely and pyproj, and writes the shapefile that
# gets uploaded. The demos read the Census boundary and TIGER road files straight
# out of a BytesIO with it.
geopandas
